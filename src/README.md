# 📝 Lista de Tarefas — Meu Primeiro Projeto React

Este é o meu **primeiro projeto desenvolvido em React**, criado como parte do aprendizado no curso de *Introdução ao React* da Udemy. O projeto foi totalmente desenvolvido e testado utilizando o ambiente online **CodeSandbox**.

Trata-se de um gerenciador de tarefas simples, mas funcional, focado na prática de conceitos essenciais do React, como componentes, gerenciamento de estado (`useState`) e manipulação de listas.

---

## 🚀 Funcionalidades

O aplicativo permite gerenciar suas tarefas diárias de forma dinâmica, organizando-as por estágios:

*   **Criar Tarefas:** Adicione novas tarefas à sua lista rapidamente.
*   **Mudar o Estágio:** Organize suas tarefas alterando o status atual delas:
    *   ⏳ **Pendentes**
    *   ⚡ **Em execução**
    *   ✅ **Cocluídas**
*   **Interface Simples:** Layout intuitivo projetado para facilitar a visualização do fluxo de trabalho.

---

## 🛠️ Tecnologias Utilizadas

*   **React** (Biblioteca JavaScript para construção de interfaces)
*   **CSS** (Estilização dos componentes)
*   **CodeSandbox** (Ambiente de desenvolvimento online)

---

## 💡 Conceitos de React Praticados

Durante o desenvolvimento deste projeto, coloquei em prática:
1.  **Componentização:** Divisão da interface em blocos menores e reutilizáveis.
2.  **Estado (`useState`):** Controle dinâmico da lista de tarefas e das mudanças de estágio.
3.  **Props:** Passagem de dados e funções entre os componentes pais e filhos.
